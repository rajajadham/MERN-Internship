# 🌤️ API Weather App

A responsive weather application built using HTML, CSS and JavaScript.

## Features

- Search weather by city name
- Live weather data
- Temperature in Celsius
- Weather condition
- Weather icon
- Humidity
- Wind speed
- Feels-like temperature
- Loading animation
- Error handling
- Responsive design
- Weather-based background
- OpenWeatherMap API integration

## Technologies Used

- HTML5
- CSS3
- JavaScript ES6+
- Fetch API
- Async/Await
- OpenWeatherMap API

## API Source

OpenWeatherMap API:

https://openweathermap.org/api
